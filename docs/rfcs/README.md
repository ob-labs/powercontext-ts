# RFCs

Cross-language product RFCs live in the Python reference:

- https://github.com/oceanbase/powercontext/tree/main/docs/en/rfcs

This repository does not fork that process. TypeScript parity reads the
machine-checked [RFC ledger](../policies/rfc-ledger.yaml):

- `implemented` and still matching pinned Python may be a parity source.
- `draft` and `accepted-not-implemented` are not current TypeScript
  requirements.
- Draft extras must not become hidden M4 work.

Architecture choices that only constrain this repository are recorded as
[ADRs](../adr/README.md).
